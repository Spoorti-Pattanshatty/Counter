# 🌸 Counter Web Application

A simple and interactive Counter Web App built using **HTML, CSS, and JavaScript**.
This project demonstrates basic DOM manipulation and event handling with a clean and modern UI.

---

## 🚀 Features

* ➕ Increase counter value
* ➖ Decrease counter value
* 🔄 Reset counter
* 🎨 Stylish UI with background image
* 📱 Responsive design

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript 

---

## 📂 Project Structure

```
project/
│── index.html
│── style.css
│── index.js
│── bg.jpg
│── README.md
```

---

## ▶️ How to Run the Project

1. Download or clone the repository
2. Open the project folder
3. Double-click on **index.html**
4. The app will open in your browser
